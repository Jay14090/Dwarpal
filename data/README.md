# data/ (gitignored)

Created and filled locally; nothing here is committed.

- `raw/`        downloaded dataset subsets and your own clips (`raw/gate_vehicles/` for P5)
- `processed/`  common format: `<dataset>/<camera>.mp4`, `gt/<camera>.json`, `calibration/<camera>.json`
- `cache/`      per-frame cached detections for `run_mode: cached` cameras
- `thumbs/`     track and plate thumbnails
- `clips/`      short clips returned by search
